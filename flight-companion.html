BUSW Flight Companion

A live descent and flight-guidance companion for Microsoft Flight Simulator and X-Plane. It reads your running simulator and updates continuously as you fly, instead of giving you a single static number. It is a focused companion, not a full EFB.

Release and downloads

Key capabilities

Version 0.4.0, “The Copilot”, adds wind-aware descent planning, STAR altitude-constraint handling, audio guidance, and post-TOD profile monitoring.

Descent planning

  • Live, wind-aware Top-of-Descent planning
  • STAR altitude-constraint handling
  • Post-TOD descent-profile monitoring

Guidance and awareness

  • Audio flight-guidance callouts
  • 9-phase automatic flight-phase detection, with manual override

Route and simulator

  • SimBrief route import for live distance-remaining tracking
  • Improved simulator connection and aircraft-profile tracking
  • Native Windows desktop app with Setup and Dev Tools pages

v0.4.0 Pre-Alpha — The Copilot

Platform
Windows 10/11
Simulators
Microsoft Flight Simulator 2020/2024 or X-Plane 11/12 (optional)
Distribution
Installer or portable executable. Both are unsigned, so Windows SmartScreen will show an “unrecognized app” warning on first run.

Pre-alpha limitations

  • v0.4.0 is Pre-Alpha software and has not yet completed comprehensive validation during a full live MSFS flight.
  • Flight Companion is for flight simulation only. Do not use its recommendations as real-world flight-operational guidance.
