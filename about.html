About Balkan Universal Software Works

BUSW is an independent software studio founded and maintained by Eymen Balkan, who designs, builds, and ships every product end to end.

Its public development project is BUSW Flight Companion, a live descent and flight-phase companion for flight simulation. It is built around one principle: everything that can be detected automatically should be, manual input exists only as an override, and the person using it always has final authority.

BUSW is also developing a website builder, currently in development. You can read about both on the Products page.
