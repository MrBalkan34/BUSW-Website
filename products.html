BUSW Flight Companion

v0.4.0 Pre-Alpha — The Copilot

BUSW Flight Companion connects directly to your running flight simulator — Microsoft Flight Simulator 2020/2024 or X-Plane — and tells you when to start descending, updating live as you fly instead of giving you a single static number. v0.4.0 — “The Copilot” — adds wind-aware descent planning, STAR altitude- constraint handling, audio guidance, and post-TOD profile monitoring. Automatic flight-phase detection remains available with full manual override, while SimBrief import pulls in your filed route for live distance tracking. It's a focused descent and flight-guidance companion, not a full EFB — currently available as a public Pre-Alpha Windows desktop app.

  • Live, wind-aware Top-of-Descent planning
  • STAR altitude-constraint handling
  • Audio flight-guidance callouts
  • Post-TOD descent-profile monitoring
  • 9-phase automatic flight-phase detection, with manual override
  • SimBrief route import for live distance-remaining tracking
  • Improved simulator connection and aircraft-profile tracking
  • Native Windows desktop app with Setup and Dev Tools pages
Download installer (.exe) Download portable (.exe) View v0.4.0 release on GitHub

Windows 10/11 · Microsoft Flight Simulator 2020/2024 or X-Plane 11/12 (optional) · Unsigned executable — Windows SmartScreen will show an "unrecognized app" warning on first run. v0.4.0 is Pre-Alpha software and has not yet completed comprehensive validation during a full live MSFS flight; do not use its recommendations as real-world flight-operational guidance.
