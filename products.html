BFC

BUSW Flight Companion

Development project · Public pre-alpha

A live descent and flight-guidance companion for Microsoft Flight Simulator and X-Plane. It reads your running simulator and updates continuously as you fly, instead of giving you a single static number.

  • Live, wind-aware Top-of-Descent planning
  • STAR altitude-constraint handling
  • Audio flight-guidance callouts
  • Post-TOD descent-profile monitoring

Latest release v0.4.0 · Windows 10/11 · For flight simulation use only.
